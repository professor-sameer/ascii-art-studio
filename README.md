
# ASCII Art Studio

A Python desktop application that transforms photographs into text-based ASCII artwork.

## Features

- Open PNG, JPG, JPEG, BMP, and WebP images
- Choose from four character styles: Classic, Dense, Minimal, and Block
- Adjust output width and contrast
- Apply image sharpening and smoothing
- Preview artwork in a scrollable desktop window
- Export generated ASCII artwork as a TXT file

## Built With

- Python
- Tkinter
- Pillow

## Requirements

- Python 3
- Pillow

## Run Locally

Install the dependency:

```bash
python -m pip install -r requirements.txt
```

Run the application:

```bash
python ascii_studio.py
```
